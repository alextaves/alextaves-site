Type scale quick reference

The ratio sets the distance between steps, not the sizes. You are not obliged to use every rung.

pt, set on the body

Below 8.5pt. The arithmetic is correct and the result is unreadable. Move it up a step, or set it by hand and note that you broke the scale on purpose.

Rounding to the nearest half point will not break the relationship. The ratio is the point, not the decimals.
